Your private forwarding address

…

Anything sent to this address with a POST request is read as a message for your account. Keep it private, and use Reset if it leaks. It must be a public address (for example your Render URL) for phones and Gmail to reach it.

Gmail
  1. Download your Gmail script (your address is already filled in).
  2. Open script.google.com, create a project and paste it.
  3. Run forwardOrderEmails once and allow access.
  4. Add a time-driven trigger: every 15 minutes.
iPhone (Shortcuts)
  1. Shortcuts → Automation → New → Message.
  2. Set Message contains “order”, choose Run immediately.
  3. Add Get Contents of URL: paste your address, Method POST, Request body JSON with key body = Shortcut Input and source = SMS.
Android (SMS)
  1. Install an “SMS forwarder to webhook” app from the Play Store.
  2. Add a rule for messages containing “order”, “shipped” or “delivered”.
  3. Set the webhook URL to your address (POST). Plain text or JSON both work.
